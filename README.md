# Mariel Confecciones V1.0

## Descripción

Sitio web desarrollado para Mariel Confecciones, un emprendimiento dedicado a la confección e indumentaria femenina.

El proyecto incluye:

- Catálogo de productos online
- Panel de administración
- Gestión de productos
- Subida de imágenes
- Edición y eliminación de productos
- Integración con Supabase
- Publicación automática mediante Netlify

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- Git
- GitHub
- Netlify

## Funcionalidades

### Sitio público

- Visualización de categorías
- Catálogo de productos
- Vista ampliada de imágenes
- Botón de contacto por WhatsApp
- Diseño adaptable

### Panel administrador

- Inicio de sesión
- Alta de productos
- Edición de productos
- Eliminación de productos
- Gestión de imágenes
